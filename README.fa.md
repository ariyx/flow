# Webilo Flow

وبیلو فلو یک محصول خصوصی برای ساخت تصویری ربات‌های تلگرام است. نسخه `v0.1 — Origin` بیشتر با هدف نمونه‌کار حرفه‌ای، ارائه برای Webilo و رزومه مالک محصول ساخته می‌شود، اما معماری آن باید مسیر گسترش آینده را باز نگه دارد.

اصل اصلی پروژه:

> ساده‌ترین معماری‌ای را بساز که نسخه اول را قابل‌اعتماد و قابل‌ارائه کند؛ نه بیشتر.

برای جزئیات فنی و محصول، فایل‌های انگلیسی داخل `docs/` منبع اصلی هستند.
