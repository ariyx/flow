# Contributing

This is a private, proprietary repository.

## Workflow

1. Create or select a GitHub Issue.
2. Use a focused branch: `feature/<issue>-<name>` or `fix/<issue>-<name>`.
3. Implement one coherent feature or fix.
4. Add tests and update documentation.
5. Open a pull request using the repository template.
6. Merge only after CI passes.

Use Conventional Commits, for example:

```text
feat(builder): add ask question node
fix(runtime): prevent duplicate update processing
docs(architecture): clarify flow ownership
```
