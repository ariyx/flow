# Execution Plans

Use an execution plan for work that spans multiple modules, changes contracts or database state, or is likely to require several implementation steps.

## Template

```markdown
# Plan: <title>

## Goal

## Current state

## Proposed changes

## Files and modules affected

## Data and contract changes

## Test strategy

## Risks

## Implementation steps

## Completion evidence
```

Keep plans current while implementing. Record deviations and their reasons.
