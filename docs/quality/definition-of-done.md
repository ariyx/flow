# Definition of Done

A feature is done when:

- The agreed acceptance criteria pass.
- Required tests are present and passing.
- Authorization and workspace isolation are verified.
- Loading, empty and error states are handled where applicable.
- User-facing text uses localization keys.
- API, JSON Schema and examples are updated when relevant.
- Documentation reflects the implemented behavior.
- No secrets, temporary debug output or sensitive data remain.
- CI is green.
- The implementation does not add deferred scope or unnecessary infrastructure.
