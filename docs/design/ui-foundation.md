# Flow UI Foundation

## Direction

Minimal, technical and premium.

The interface should feel focused and product-oriented rather than decorative
or marketing-oriented.

## Colors

- Background: `#080B0F`
- Surface: `#11161D`
- Surface 2: `#161C24`
- Border: `#232A33`
- Text: `#EBEAF1`
- Muted: `#8E96A3`
- Primary: `#7C3AED`
- Primary Hover: `#6D28D9`
- Success: `#10B981`
- Warning: `#F59E0B`
- Danger: `#EF4444`

## Radius

- sm: 6px
- md: 8px
- lg: 12px
- xl: 16px

## Spacing

4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48

## Principles

- Dark-first.
- Prefer borders over heavy shadows.
- Use purple selectively.
- Avoid excessive gradients.
- Avoid oversized cards and excessive whitespace.
- Keep application UI more compact than marketing UI.
- Every screen must be responsive.
- Use existing Tailwind and shadcn/ui primitives where practical.
- Do not create a large custom design-system framework.
