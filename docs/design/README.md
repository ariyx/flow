# Flow Design

Design references and specifications for the Webilo Flow application.

## Source of truth

Product requirements and milestone documentation define what must exist.

Design documents define how approved UI should look and behave.

Reference images are visual targets, not product specifications.

When implementing UI:

1. Read `ui-foundation.md`.
2. Read the relevant file under `screens/`.
3. Inspect the associated image under `references/`.
4. Follow the current milestone scope.
5. Do not implement placeholder or future features shown only in screenshots.
