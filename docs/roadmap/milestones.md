# V0.1 Milestones

Development follows vertical slices. Each milestone should produce a demonstrable, tested outcome.

## M0 — Foundation

- Monorepo and Docker Compose
- React, Laravel and Go applications
- PostgreSQL and Redis
- Contracts package
- CI, formatting and linting
- Authentication and automatic workspace
- Health checks and basic logging
- Initial documentation

## M1 — Bot Management

- Token validation
- Encrypted storage and masking
- Automatic webhook setup
- Bot overview
- Enable, disable, disconnect and soft delete
- Fake Telegram client
- Simple Filament administration

## M2 — Builder Foundation

- Flow list and create flow
- React Flow canvas
- Node library and properties panel
- Draft persistence and auto-save
- Undo, redo, duplicate and delete
- Validation presentation

## M3 — Runtime Core

- Runtime schema and compiler
- Immutable publishing
- Webhook ingestion and duplicate protection
- Trigger matching
- Execution lifecycle and events
- Per-user Redis lock
- Start, command, text, send-message and end nodes

## M4 — Interactive Flows

- Ask Question and resume
- Input validation and custom error text
- Variables
- Condition and branching
- Inline buttons and callbacks
- Go To and loop protection
- Waiting expiration

## M5 — Test and Debug

- Telegram test code flow
- Draft test execution
- Execution list and timeline
- Variables inspector
- Retry and reset behavior
- Test node states in builder

## M6 — Templates and Submissions

- Template gallery and preview
- Four Webilo templates
- Template cloning
- Submissions and statuses
- Read-only Telegram users

## M7 — Product Polish

- Dashboard and onboarding checklist
- Light and dark themes
- Empty, loading and error states
- Responsive list pages
- Localization completeness
- Dangerous-action confirmations
- Demo seed data

## M8 — Hardening and Release

- Critical E2E and integration tests
- Backup and restore test
- Cleanup jobs
- Error tracking
- Basic runtime metrics and health checks
- Rate limiting and security review
- Production deployment documentation
- Online demo and v0.1.0 release
