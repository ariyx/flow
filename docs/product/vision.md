# Product Vision

## Vision

Enable business owners, Telegram channel administrators and interested creators to build useful Telegram bot MVPs visually, without writing code.

## Primary value

1. Build a working Telegram bot MVP quickly.
2. Start from Webilo templates and customize behavior visually.
3. Publish and debug real flows without editing application code.

## V0.1 positioning

V0.1 is a portfolio-ready Product Alpha. It must be real, polished and technically credible, but it is not a commercial automation platform or enterprise SaaS release.

## Product principles

- Telegram-only focus
- Hybrid builder with template-first onboarding
- Reliability before feature count
- Simple language for non-technical users
- Clean architecture with a path to future expansion
- No premature platform engineering
