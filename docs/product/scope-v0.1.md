# V0.1 Scope

## Must-have

- Email/password authentication
- Automatic workspace
- Telegram bot connection and webhook management
- Visual builder and approved node set
- Draft, validation, test publish and immutable publishing
- Go runtime with durable execution state
- Waiting/resume behavior
- Execution timeline
- Four internal templates
- Submissions
- Critical security and reliability tests
- Docker Compose deployment and online demo

## Should-have

- Dark mode
- Read-only Telegram users
- Dashboard summary metrics
- Template preview
- Node status visualization in test mode
- BotFather instructions
- Simple Filament admin view

## Could-have

- Small visual analytics
- Additional keyboard shortcuts
- Export of selected data
- Decorative execution animation

## Explicitly deferred

- Billing and subscriptions
- Broadcasts
- Team collaboration UI
- Marketplace
- AI nodes
- HTTP request node
- Custom code node
- Payment nodes
- Scheduled triggers
- File or photo input from users
- Reply keyboards
- Advanced analytics
- Public API
- Plugin SDK
- A/B testing
- Real-time collaboration
- Multiple deployment environments
- White label
- Kubernetes, Kafka, Temporal and additional infrastructure services

## Scope change rule

A new v0.1 feature requires removal or deferral of another feature unless it resolves a release-blocking requirement.
